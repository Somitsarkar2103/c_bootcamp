# C Programming Bootcamp 🚀

## 📚 About

This repository contains my learning and practice work from a **C Programming Bootcamp**.

The main goal of this bootcamp is to understand the fundamentals of C programming and improve problem-solving and programming skills through regular practice.

* Introduction to C Programming
* Variables and Data Types
* Input and Output
* Operators
* Conditional Statements

  * `if`

  * `else-if`
  * `switch`
* Loops

  * `for`

* Functions
* Arrays
* Strings
* Pointers
* Structures
* Dynamic Memory Allocation
* Basic Data Structures
* Problem Solving
